ML Pipeline
How the System Works
From raw patient data to clinical prediction in milliseconds.
1

Data Collection & Preprocessing

3,000 patient records from Kaggle with 14 features: demographics, symptoms, comorbidities, vaccination status. Label Encoding + Standard Scaling applied.

2

SMOTE — Handling Class Imbalance

Synthetic Minority Oversampling applied. Dataset has class imbalance (non-hospitalized majority). SMOTE generates synthetic samples for the minority class to improve model fairness.

3

Multi-Model Training

Logistic Regression, Random Forest (200 trees), Gradient Boosting (200 estimators), and XGBoost trained. 80/20 stratified split ensures fair evaluation.

4

Evaluation & Model Selection

5-fold Stratified Cross-Validation with AUC-ROC scoring. XGBoost achieves the best AUC of 0.93. Final model selected based on accuracy, AUC, and clinical interpretability.
